# Third-party listings & off-page checklist (2026-08-02)

These directories RANK for our money queries ("pocket alternative", "X vs Y")
and are the fastest fix for the off-page gap identified in the June audit.
Order = priority.

## 1. AlternativeTo (highest leverage — do first)

- Claim/complete the Marqly listing: alternativeto.net — description from the
  facts sheet, all platform tags (Chrome, Edge, Firefox, Safari, iOS, Web),
  screenshots, "AI bookmark manager" + "read it later" + "web highlighter" tags.
- Register Marqly as an alternative TO: Pocket, Raindrop.io, Instapaper,
  Readwise Reader, Omnivore, Matter, mymind, Diigo, GoodLinks, Evernote Web
  Clipper, Notion Web Clipper.
- AlternativeTo ranks by user "likes": add a gentle prompt in the newsletter /
  post-onboarding email — never incentivized (against their rules).

## 2. Product Hunt (refresh)

- Existing listing: producthunt.com/products/marqly (★4.7). Add the YouTube AI
  card + free tools as new "Launches" (PH allows feature launches). Free tools
  are ideal PH fodder: "Free YouTube transcript viewer — no signup".

## 3. G2 + Capterra

- Create vendor profiles (both free). Category: Bookmark Manager / Productivity.
  G2 comparison pages ("Raindrop vs Pocket") rank top-5 for "X vs Y" queries —
  being listed puts Marqly in the comparison widgets.
- Seed 5-10 genuine reviews via an email to happy users (both platforms verify
  reviewers; never pay for reviews).

## 4. Pocket-shutdown roundups (link building)

Dozens of "best Pocket alternatives" articles update regularly (The Verge,
ZDNet, MakeUseOf, Lifehacker, niche blogs). Pitch inclusion with a 3-line email:
what Marqly is, the one-tap Pocket import, free tier. Track in a sheet; 10
pitches/week. Our own /alternatives/pocket + /tools/pocket-export-converter are
the link targets.

## 5. Slant, ToolFinder, StackShare, SaaSHub

Complete profiles once each; low effort, permanent backlinks, occasional
referrals.

## 6. Reddit / HN presence (organic only)

r/DataHoarder, r/productivity, r/selfhosted (be honest: we're not self-hosted —
participate where relevant, e.g. Pocket-migration threads). Answer genuinely,
disclose affiliation, link the free tools rather than the homepage.

## Cadence

Week 1: AlternativeTo + PH launch of free tools. Week 2: G2 + Capterra. Weeks
3+: roundup pitches ongoing. Revisit quarterly.
