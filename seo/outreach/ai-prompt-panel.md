# AI-citation tracking panel — 30 prompts, weekly (Phase 5.1)

Run each prompt weekly in all four surfaces (ChatGPT w/ search, Perplexity, Google AI Mode, Copilot),
record ONE row per prompt×engine in `seo/data/ai-citations.csv`. Rule: record what the answer actually
said — never backfill from memory; screenshot/URL evidence in the notes column.

Columns: run_date, engine, prompt_id, prompt, marqly_cited (0/1), position (1-based rank in listed
tools, blank if not listed), competitors_cited (comma list), evidence_url/notes.
