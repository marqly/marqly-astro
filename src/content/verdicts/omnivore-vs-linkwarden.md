Start with the disqualifier: Omnivore's hosted service no longer exists. It shut down in November 2024 after the team joined ElevenLabs, with a one-month export window before deletion — a hard ending for a free, open-source reader that had earned real affection. Its code survives in volunteer forks, but running the original stack means PostgreSQL, Elasticsearch, and a cluster of microservices. Linkwarden is what a sustainable open-source project looks like instead: AGPL-licensed with free, full-featured self-hosting, a $3/month cloud that funds development, and a focus Omnivore never had — every saved link archived as a screenshot, PDF, and readable copy so your library outlives the web it came from.

**Choose Linkwarden if:**

- You want an open-source tool with a future — active releases, official iOS and Android apps since late 2025
- Preservation beats presentation: automatic page archiving, nested collections, and full-text search across it all
- You collaborate or share — public collections and per-user permissions were never Omnivore features

**Choose an Omnivore fork only if:**

- You're committed to self-hosting a volunteer-maintained reading app despite the operational weight
- Omnivore's specific reader experience and search syntax are worth that ongoing cost to you

Bottom line: the honest note is that these were never quite the same product. Omnivore was for reading; Linkwarden is for keeping — it has no reading queue, no text-to-speech, and no reading progress. Former Omnivore users wanting a true reading replacement should weigh Wallabag or a commercial reader instead. But between these two names, one is a memorial and the other is maintained: Linkwarden, without hesitation.
