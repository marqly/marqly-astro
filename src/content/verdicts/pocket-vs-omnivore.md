This is a comparison between two ghosts, and they died for opposite reasons. Pocket was a corporate product with revenue — a free tier plus Premium — that Mozilla killed anyway when it chose to refocus on Firefox. Omnivore was open-source idealism: completely free, no paid plan ever, funded by its founders — which meant that when the team joined ElevenLabs in late October 2024, the hosted service had no reason to keep running and closed within a month. Different failure modes, same lesson: a service is only as durable as its reason to exist.

**Choose Pocket if**

- You can't, in any form. The service ended July 8, 2025; exports closed October 8, 2025; everything left was deleted. There is no code to run and no fork to join.
- Its sixteen-year run survives only in the export ZIPs its users downloaded.

**Choose Omnivore if**

- Only in one narrow sense: the AGPL code lives on GitHub with well over a thousand forks, so a determined self-hoster can run a community fork today.
- Be honest about the cost — the original stack demands PostgreSQL, Elasticsearch, and multiple microservices, and forks are volunteer-maintained with no guarantees.

Where the user bases actually went says more than any feature table. Pocket readers scattered to Instapaper and Matter — the closest reading experiences, both with Pocket importers — and to Raindrop.io for collecting. Omnivore's community mostly chose Wallabag, the boring, stable elder of self-hosted read-it-later, or Linkwarden and Karakeep for archiving and AI, while its heaviest readers paid for Readwise Reader. If you hold an export from either service, nearly every living tool can ingest it. If you don't, both deletion deadlines passed long ago, and the practical takeaway is simply this: pick a successor whose business model you believe in, because both of these deaths were predictable in hindsight.
