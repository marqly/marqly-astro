Yes. Marqly has a dedicated add-on in the Microsoft Edge Add-ons store, so you install it the same way you'd install any Edge extension. And because Edge is built on Chromium, the Chrome Web Store listing installs and runs in Edge too. Either route gives you the same extension: one-click saving, AI auto-tagging, and your full library in the side panel.

## Two ways to install

**Option 1 — the Edge add-on (recommended).** Open the [Marqly listing on Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/marqly-%E2%80%93-the-ultimate-boo/gojjglmdginjjpgajdnobmnkmcogngok) and click **Get**. This is the native route: installs and updates flow through Microsoft's own store.

**Option 2 — the Chrome Web Store listing.** Edge can install extensions straight from the [Chrome Web Store](https://chromewebstore.google.com/detail/marqly-all-in-one-bookmar/kcadneobjofkppmekgadodnaojoehemc). Edge will ask you to allow extensions from other stores the first time; after that, "Add to Chrome" works as an install button in Edge.

There's no functional difference in the extension you end up with — pick whichever store you prefer.

## Same Marqly, same account

Whatever browser you install in, you sign in to the same Marqly account. Saves made in Edge show up instantly in the web app at [app.marqly.com](https://app.marqly.com), in Chrome or Firefox if you use them elsewhere, and in the iOS app. If you split your time between browsers — say, Edge for work and Chrome at home — your library stays one library. Details in [can I sync across devices](/faq/can-i-sync-across-devices).

## After installing

Pin the Marqly icon to Edge's toolbar so saving stays one click away, then sign in or create a free account — no credit card required. If you're coming from plain Edge favorites, you can export them as an HTML file and import the lot; Marqly's AI tags everything automatically. The process is the same as described in [how do I install the Chrome extension](/faq/how-do-i-install-the-chrome-extension), just inside Edge.
