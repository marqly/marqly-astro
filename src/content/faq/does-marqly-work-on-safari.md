Yes. Marqly has a Safari extension, so Mac users don't need to switch browsers to get one-click saving, AI auto-tagging, and semantic search. On iPhone and iPad, the dedicated Marqly iOS app covers you. Everything runs on the same account: a page saved from Safari is immediately available in the web app, in any other browser where you use Marqly, and on your iOS devices.

## Safari on the Mac

The Safari extension brings Marqly's core workflow to Apple's browser: save the page you're on, add tags if you want (AI tags it automatically either way), and search your library later by describing what you remember — no folder archaeology. For install steps and setup help, see the [Marqly help center](https://help.marqly.com).

Safari is one of four browsers Marqly supports, alongside Chrome, Edge, and Firefox. If you run a mixed setup — Safari for personal browsing, Chrome for work — install Marqly in both and the saves land in one shared library.

## iPhone and iPad

For mobile Safari users, the better tool is the [Marqly iOS app on the App Store](https://apps.apple.com/us/app/marqly-ai-bookmark-manager/id6758905385). It gives you your full library — every save, tag, and highlight from your desktop browsers — on your phone, with the same search. More in [is there an iOS app](/faq/is-there-an-ios-app).

## Moving Safari bookmarks into Marqly

Safari exports bookmarks as a standard HTML file, the same format Chrome, Edge, and Firefox use — and Marqly imports that format directly. Export from Safari, import the file into Marqly, and AI auto-tags the whole set, turning an old bookmarks menu into a searchable library. The steps mirror the Chrome walkthrough in [how to import Chrome bookmarks into an AI bookmark manager](/blog/how-to-import-chrome-bookmarks-to-ai).

## One account, every Apple device

Sign up once at [app.marqly.com](https://app.marqly.com) — free, no credit card — and the same login works in the Safari extension, the web app, and the iOS app. Your library is the same everywhere because it lives in your account, not on any one device.
