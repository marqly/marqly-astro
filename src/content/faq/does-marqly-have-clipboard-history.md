Yes. On Chrome and Edge, Marqly's Clipboard History automatically keeps text you copy from webpages so it does not disappear when you copy something else. Open the Clipboard workspace to search, filter, pin, favorite, and tag the snippets you want to keep.

## A searchable place for copied text

A normal browser clipboard is temporary: copying a second item replaces the first. Marqly turns those copied snippets into a small, searchable history beside your bookmarks. Use it for research notes, quotes, addresses, code snippets, or any other webpage text that is useful but does not need to become a full bookmark.

## Favorites, pins, tags, and filters

Favorite or pin the items you need repeatedly, add tags to create your own structure, and filter the list when it gets longer. For text that belongs to a source page and needs lasting context, use [web highlights](/faq/how-do-i-highlight-text-on-a-website) instead; highlights remain attached to the original webpage.

## Browser and sync availability

Clipboard History is currently available in the Chrome and Microsoft Edge extensions. It is not currently available in Firefox or Safari. Clipboard capture works in the browser, and Marqly Pro adds account sync for clipboard items. See the [complete extension feature and browser table](/extension) before choosing a browser.
