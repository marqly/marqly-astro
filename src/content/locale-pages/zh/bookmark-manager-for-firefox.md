论“书签的讲究程度”，Firefox 用户的主张比任何浏览器人群都硬：Firefox 支持书签标签和关键词检索已经很多年，早于其他家在意这件事。但症结也一直是同一个：每个标签都得亲手敲，搜索仍然只匹配你精确用过的词。Marqly 发布在 [Firefox Add-ons（AMO）](https://addons.mozilla.org/en-US/firefox/addon/marqly/)上的扩展，保留了 Firefox 体系的神，抽掉了它的劳动：每次收藏由AI自动打标、自动摘要，日后凭“你记得什么”描述即可找回——不要求命中确切词句。

## 骨架很好，一切都是手动

Firefox 的书签库确实是多数浏览器给不出的更好家具：标签、关键词、一个真正的管理窗口。但这件家具需要你亲手组装，永远。给每条收藏手敲标签是一种税负，而税总会被逃掉——多数 Firefox 用户的打标纪律维持三周左右，之后书签库悄悄变成和所有人一样的无标签乱堆。

搜索再好用，也还是词法的：它匹配标题、URL 或你写过的标签，而不是页面讲的是什么。当你对一次收藏的记忆是“那篇谈注意力与笔记术的长文”，用你自己三周前的标签词表做关键词搜索，通常一无所获。同时 Firefox Sync 只在你的 Firefox 安装之间搬运书签，哪儿也不去——只要你的白天要碰公司电脑的 Chrome 或 iPhone 上的 Safari，这套库就留在原地。

## 扩展每天在干的活

Marqly 的 Firefox 扩展把保存变成一次工具栏点击，自律者仍可在收藏时顺手加标签。其余所有人拿到的都是AI自动打标：每条收藏自动贴好标签，不用归档，也不用维护一套标签词表。文章收藏还会生成AI摘要——这才是让积压存量变得“可复盘”的关键：扫一眼摘要，做出判断，继续前进。

几个功能在捕获之外做真正的重活。标签页保存器把所有打开的标签一次入库，体面结束30个标签页的调研现场。侧边栏书库把浏览与搜索放在你正在读的页面旁边。高亮器在任意网站以六色标记文字、可选笔记——回访时标记仍在页面上，并同步进书库。YouTube 上有AI卡片提供流式摘要、播放同步的逐字稿，Pro 还有基于逐字稿作答的对话标签页，操作栏里的收藏按钮则让视频连逐字稿一起入库。另有存为PDF：按屏幕版式抓取任意页面的干净PDF，浏览器本地处理。

取回才是回报。语义搜索横跨标题、正文、高亮与逐字稿按含义匹配——[按描述搜索是怎么工作的](/zh/blog/ai-shuqian-sousuo-2026)。这是 Firefox 标签思路的完成态：元数据自己写自己，搜索也不再要求它写得多精确。

## 把你已经建好的库带来

你多年的 Firefox 书签会一起搬过来。Firefox 能把整个书签库导出为标准书签HTML文件（书签 → 管理书签 → 导入和备份 → 导出），Marqly 直接导入这一格式——与[导入 Chrome 书签](/zh/blog/chrome-shuqian-daoru-zhinan-2026)是同一套流程，Pocket 的 list.csv 导出与 Raindrop.io 的HTML收藏也支持。导入时由AI统一打标与处理，那一刻，十年积累的收藏从“按2019年随手起的名字查”变成“按含义查”。（注意：导入不保留原始收藏日期，条目以导入当日入库。）

此后书库与浏览器无关：账号[跨设备同步](/faq/can-i-sync-across-devices)，同样的收藏可从 Chrome、Edge、Safari 扩展、任意浏览器里的网页版和 iOS App 访问。画板补上 Firefox 从未有过的分享层——按项目归组链接与高亮，再把画板作为公开页面分享，任何人可看、无需账号。

4. 明天，用一句描述去搜一条旧收藏——第一次“凭模糊记忆命中”的瞬间，就是这件工具自证价值的时刻。
