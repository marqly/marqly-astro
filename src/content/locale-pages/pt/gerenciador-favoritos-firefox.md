O sistema de tags do Firefox é poderoso, mas o trabalho manual de etiquetar cada link acaba sendo abandonado com o tempo.

O Marqly resolve isso: a IA analisa, classifica e resume cada página salva, permitindo que você encontre qualquer link por linguagem natural.
