Você precisa de uma cópia de uma página que não vai mudar nem sumir: uma página de confirmação de compra, um artigo que você vai citar, uma vaga de emprego que pode sair do ar amanhã, uma página de vendas que quer consultar depois do redesign. O imprimir-em-PDF embutido do navegador nunca foi feito para esse trabalho. Ele passa a página pelas folhas de estilo de impressão, descarta imagens que ainda não carregaram e quebra layouts em lugares estranhos.

O Marqly resolve de outro jeito. Clique na extensão e a página é capturada como um PDF limpo que casa com o que está de fato na sua tela — lazy-load incluso —, processado localmente no seu navegador. Esta página explica o que a captura faz e por que ela mora dentro de um gerenciador de favoritos; se você quer o passo a passo clique a clique, está em [como salvar uma página web como PDF](/pt/blog/salvar-pagina-web-como-pdf).

## Uma captura que bate com a sua tela

O imprimir-em-PDF renderiza a página pela folha de estilo de impressão, e na maioria dos sites essa folha é um enfeite esquecido. Barras laterais desabam para a coluna principal, fontes customizadas caem no padrão do sistema, tema escuro inverte para um cinza ilegível, e layouts de várias colunas se partem no meio da frase entre páginas. O resultado é tecnicamente um PDF da página, mas não parece a página que você queria guardar.

A captura do Marqly é fiel à tela. Ela registra a página como ela renderiza no seu navegador, então o layout que você vê é o layout que você recebe. Para referência de design, artigo bem diagramado ou qualquer página em que a arrumação visual carrega sentido, essa diferença é o ponto inteiro. Você não está arquivando um despejo de texto; está guardando a página.

## As imagens com carregamento tardio entram no arquivo

Páginas modernas não carregam as imagens de uma vez. Elas carregam conforme você rola — o que economiza banda para o site e sabota ferramentas de captura ingênuas: mande imprimir um artigo longo sem rolar até o fim primeiro, e metade das imagens sai como placeholder em branco.

A captura do Marqly inclui as imagens lazy-loaded. Um artigo de 4.000 palavras com trinta fotos sai com trinta fotos, não com trinta caixas cinzas e um lembrete para refazer. Se você já rolou uma página inteira de cima a baixo antes de imprimir só para forçar as imagens a aparecerem, é esse passo que você para de fazer.

## Processado local, então não tem nada para esperar

A conversão acontece no seu navegador. A página não é despachada para um servidor de conversão de terceiros nem enfileirada atrás do lote de outra pessoa — a extensão faz o trabalho na sua máquina, e a captura termina quando o clique termina.

O processamento local mantém o fluxo simples: sem etapa de upload, sem serviço externo entre você e o arquivo. É a mesma razão pela qual a captura é rápida o bastante para virar hábito — para comprovantes e páginas de referência, não só para aquela grande tarefa de arquivamento ocasional.

## O PDF cai numa biblioteca, não na pasta Downloads

Uma pasta de arquivos chamados `download (14).pdf` é para onde páginas salvas vão para se perder. No Marqly, a captura é um salvamento como qualquer outro: a IA aplica tags automaticamente, então não há arquivamento manual, e a busca semântica encontra o arquivo depois por descrição — «a página de preços com a tabela comparativa» funciona mesmo sem você ter dado nome ao PDF. Esse comportamento de buscar por significado está em [como pesquisar favoritos com IA](/pt/blog/o-que-e-busca-semantica).

Você também pode agrupar capturas com links e destaques relacionados num board — um lugar só para tudo que pertence a um projeto. Veja [o que são boards](/faq/what-are-boards) para saber como funciona.

## Como começar

Instale a extensão do Marqly — disponível para Chrome, Edge, Firefox e Safari — e crie uma conta grátis em [app.marqly.com](https://app.marqly.com). Sem cartão de crédito; os detalhes do plano estão em [o Marqly é grátis](/faq/is-marqly-free).

Depois abra a página que você quer guardar e salve como PDF pela extensão. A versão curta da mecânica está na FAQ: [como salvar uma página como PDF](/faq/how-do-i-save-a-page-as-pdf). É a configuração inteira — não há etapa de ajuste, template para escolher nem parâmetro de saída para tunar.

## Para quem isso não é

Checagem honesta de encaixe. O Marqly não é conversor em lote: não há API pública, então se o seu trabalho é transformar uma planilha de 500 URLs em 500 PDFs num cronômetro, você quer um serviço de conversão dedicado. Também não é editor de PDF — não dá para reordenar páginas, preencher formulários ou anotar dentro do arquivo depois da captura. E a leitura offline (Pro) só guarda em cache as páginas que você marcar, um dispositivo por vez — não escolha o Marqly como app de leitura offline-first; o PDF que você mantém no seu computador é a cópia permanente.

Onde ele entra: você esbarra regularmente em páginas que valem ser guardadas exatamente como aparecem, e quer cada uma capturada num clique e arquivada em algum lugar que você consiga realmente pesquisar. Se é esse o trabalho, a qualidade da captura — fiel à tela, imagens inclusas, processada local — é difícil de bater com uma caixa de impressão.
