Quase todo mundo que procura alternativa ao Evernote faz isso pelo mesmo motivo: **o preço subiu e o plano grátis ficou apertado**. O Starter custa 99 USD/ano e o Advanced 249,99 USD/ano. A pergunta útil é qual parte disso tudo você realmente usa.

## Faça o inventário primeiro

Abra o Evernote e veja o que tem lá dentro. Normalmente cai num destes três perfis.

**Perfil A: notas e documentos.** Você escreve bastante, anexa arquivos, digitaliza papéis. O Evernote é caro, mas coerente, e sair dá trabalho.

**Perfil B: recortes da web.** 80% do que está lá são páginas salvas com o Web Clipper, e as notas próprias são quatro. Você está pagando uma suíte por um recurso.

**Perfil C: gaveta de tudo.** Um pouco de cada coisa, sem sistema, e faz meses que você só abre para procurar algo solto.

## Se você é o perfil A

Suas alternativas reais são o **Notion** (10 USD por membro/mês no Plus, com plano gratuito usável para uso pessoal) ou o **Obsidian** (grátis, arquivos Markdown no seu disco). Os dois escrevem bem; o Marqly não compete aí porque não é editor de notas.

O que você vai perder nos dois é a digitalização de documentos com busca dentro das imagens, que continua sendo das melhores coisas do Evernote.

## Se você é o perfil B

Aqui a economia é grande e a troca é fácil, porque você só precisa mesmo salvar e reencontrar páginas.

- **Raindrop.io**, 28 USD/ano, se você gosta de organizar em coleções.
- **Marqly**, 72 USD/ano com plano grátis sem cartão, se o que você quer é não organizar nada: tags automáticas com IA, resumos e busca por significado.
- **Obsidian Web Clipper**, grátis, se você prefere Markdown local e não se importa de organizar.

Contra os 99–249,99 USD do Evernote, qualquer uma das três é um corte considerável pelo mesmo trabalho real.

## Se você é o perfil C

Seja sincero: se você não abre, migrar tudo é trabalho perdido. Exporte por segurança, comece limpo em algo mais barato e salve só o que é novo. Em seis meses você terá uma biblioteca viva em vez de um arquivo morto que você paga todo ano.
