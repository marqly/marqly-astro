Il file di esportazione di Pocket è un indice ordinato dei tuoi articoli salvati, ma non contiene i testi completi delle pagine web.

## I campi contenuti nel file

- **URL:** L'indirizzo del contenuto salvato.
- **Title:** Il titolo associato alla pagina.
- **Tags:** I tag assegnati per catalogare l'articolo.
- **Time Added:** La data di salvataggio.
- **Status:** Letto o archiviato.

## Come sfruttarlo al meglio

Importa il file in [Marqly](https://app.marqly.com) per recuperare le tue letture e sfruttare la ricerca semantica basata sull'intelligenza artificiale.
