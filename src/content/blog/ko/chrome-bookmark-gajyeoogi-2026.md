수년간 모아둔 크롬 북마크가 수백, 수천 개에 달하지만, 제목이 생각나지 않아 찾지 못하고 방치된 경험이 있으실 겁니다. 본 가이드에서는 크롬에서 북마크를 안전하게 내보내고, AI 북마크 관리자로 가져와 시맨틱(의미 기반) 검색을 활용하는 방법을 단계별로 안내합니다.

## 크롬에서 북마크 내보내는 방법

내보내기는 1분 안에 완료됩니다:

1. **북마크 관리자 열기**: 주소창에 `chrome://bookmarks` 를 입력하고 Enter를 누르거나, 단축키 `Ctrl+Shift+O` (맥은 `Cmd+Option+B`)를 누릅니다.
2. **우측 상단 메뉴 클릭**: 북마크 관리자 화면 우측 상단의 `⋮` 아이콘을 누릅니다.
3. **'북마크 내보내기' 선택**: 파일 저장 대화상자가 표시됩니다.
4. **HTML 파일 저장**: 바탕화면이나 다운로드 폴더에 `bookmarks_xxxx.html` 파일로 저장합니다.

## AI 북마크 관리자(Marqly)로 가져오기

1. [Marqly](https://app.marqly.com)에 로그인합니다.
2. 설정에서 'Import Bookmarks' 메뉴를 클릭합니다.
3. 방금 저장한 크롬 HTML 파일을 업로드합니다.
4. 기존의 폴더 구조가 컬렉션과 태그로 자동 보존되며, AI가 링크별 요약과 시맨틱 인덱싱을 백그라운드에서 진행합니다.

가져오기 과정을 거쳐도 기존 크롬 브라우저의 북마크는 삭제되지 않고 그대로 유지됩니다.
