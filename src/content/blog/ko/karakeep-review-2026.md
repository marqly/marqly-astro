Karakeep은 진짜 AI 기능 — 자동 태깅, 요약, 심지어 시맨틱 검색까지 — 을, 라이브러리를 누구에게도 넘기지 않고 쓸 수 있는 최고의 셀프 호스팅 북마크 관리자입니다. 입장료는 당신이 곧 운영팀이 된다는 것.

고지: 이 리뷰는 셀프 호스팅이 불가능한 경쟁 제품 Marqly이 발행했습니다. Karakeep은 구조적으로 우리가 못 사는 층을 서비스합니다 — "내 데이터는 내 하드웨어에"가 요구사항이라면 Karakeep이 정답일 가능성이 높고, 이 리뷰 나머지는 전부 디테일입니다. 그것 자체의 기준으로 채점하면 우수한 제품입니다.

## Karakeep이란?

Karakeep은 오픈소스 '모든 것 북마크' 앱입니다 — 링크, 노트, 이미지, PDF — 직접 설치해 쓰고, 대개 Docker로 돌립니다. Hoarder로 출발해 2025년 Karakeep으로 개명했고, 같은 프로젝트·같은 유지보수자·새 이름입니다. 이제 셀프 호스팅 세계의 대표 앱 중 하나로, GitHub 스타 28,000개 이상, 기여자 190명 이상, 꾸준한 릴리스 주기(2026년 2월 v0.31.0 출시)를 갖췄습니다.

기성 셀프 호스팅 북마크 도구들과 차별화되는 한 수: AI가 붙어 있는 게 아니라 내장되어 있습니다. 저장한 모든 것을 LLM이 자동 태깅·요약하고, 검색은 전문과 시맨틱을 함께 봅니다. API든 Ollama 로컬 모델이든 당신이 고릅니다.

서버 없이 제품만 쓰고 싶은 사람을 위해 관리형 옵션 Karakeep Cloud(현재 공개 베타)도 있습니다.

## 주요 기능

### AI 태깅과 요약 — 클라우드든 완전 로컬이든

아무거나 저장하면 Karakeep이 자동으로 태깅하고 필요하면 요약합니다. 독창적인 부분은 AI가 *어디서* 도느냐입니다. OpenAI 호환 API를 가리켜도 되고, 자기 하드웨어의 Ollama를 가리켜 네트워크 밖으로 단 1비트도 안 나갈 수도 있습니다. 이 선택지는 어떤 호스팅 경쟁자도 못 줍니다. 로컬 모델 품질은 하드웨어가 돌아가는 수준에 좌우됩니다 — 작은 로컬 모델의 태그는 프론티어 API보다 확연히 거칩니다. 다만 '옵션이 존재한다'는 사실 자체가 포인트입니다.

### 전문 검색과 시맨틱 검색

Karakeep은 저장본의 내용 전체를 인덱스하고 키워드 매칭과 함께 시맨틱 검색을 지원합니다. 검색 품질은 설정과 모델에 따라 변하지만, 아키텍처 자체가 대부분의 셀프 호스팅 경쟁자(키워드 검색에서 멈추는)보다 한 단계 앞서 있습니다.

### 전체 페이지·영상 아카이빙

페이지는 monolith로 아카이브해 링크가 썩어도 내 사본이 살아남고, 영상은 yt-dlp로 자동 아카이브할 수 있습니다. 이미지 OCR(스크린샷 수집가 여러분, 환호하세요)까지 합치면 Karakeep은 정통 '데이터 호더' 도구입니다 — Karakeep의 전신 이름(Hoarder)이 정확했다는 얘기.

### 구석구석 있는 앱과 확장

네이티브 iOS·Android 앱에 Chrome·Firefox·Safari 확장, 그리고 CLI·REST API·웹훅까지. 오픈소스 프로젝트치고 클라이언트 커버리지가 놀랍습니다 — 저희를 포함해 상용 제품 몇 개도 이기겠습니다.

### 규칙 엔진과 RSS

규칙 기반 자동화 엔진(자동 분류·자동 태깅·매칭 시 동작)과 RSS 수집으로 피드까지 모읍니다. Importer는 Chrome·Pocket·Linkwarden·Omnivore를 커버하고, Floccus로 브라우저 북마크 동기화도 됩니다. 규칙 + API + 웹훅 조합으로 Karakeep은 비범하게 자동화 가능합니다 — 커뮤니티가 스크린샷이 아니라 '레시피'를 공유하는 종류의 도구죠.

## Karakeep이 잘하는 것

- **셀프 호스팅 북마크계 최고의 AI 스토리.** 자동 태깅, 요약, 시맨틱 검색에 완전 로컬 옵션까지. 셀프 호스팅 진영에서 이 조합을 맞대응할 제품은 없습니다.
- **진정한 데이터 소유권.** 링크·노트·이미지·페이지 아카이브, 그리고 AI 처리까지 통째로 내 하드웨어 안에 둘 수 있습니다.
- **셀프 호스팅 티어는 무제한 + 무료.** 비용은 하드웨어와 선택적 API 호출뿐.
- **제법인 클라이언트 커버리지.** 네이티브 모바일 앱과 브라우저 확장 3종은 오픈소스에서 흔치 않은 사치입니다.
- **관성.** 스타 28k+, 활발한 유지보수자, 월 단위에 가까운 릴리스, 제대로 된 문서, 이름 변경을 온전히 살아넘긴 커뮤니티.

## Karakeep이 부족한 곳

- **당신이 시스템 관리자입니다.** Docker가 컴포트존인 사람에겐 설치가 쉽지만, 아닌 사람에겐 벽입니다. 업데이트, 백업, 스토리지 증가(페이지 아카이브는 쌓이면 꽤 큽니다), 리버스 프록시 보안까지 전부 영원한 당신의 일.
- **1.0 이전 소프트웨어.** 0.x 버전 번호는 솔직한 고백입니다: 업그레이드에 마이그레이션 절차가 필요할 때가 있고, 안정성은 좋은 편이지만 상용 수준으로 보장되진 않습니다.
- **AI 품질은 설정에 좌우.** 유료 API 키를 물리면 결과물도 좋습니다. 라즈베리파이의 작은 로컬 모델이면 태그와 요약이 거칠어집니다. 유연성이 기능이듯이, 편차는 비용입니다.
- **클라우드 무료 티어는 데모.** 북마크 10개로는 제품과 함께 사는 느낌을 전혀 못 줍니다. 실질 선택지는 셀프 호스팅 대 월 $4입니다.
- **마감 품질 격차.** UI는 — 진짜로 — 좋습니다. 다만 성숙한 상용 앱과 나란히 놓으면 이음매가 보입니다: 리더 뷰의 거친 부분, 가끔 놓치는 파싱, 웹 앱보다 뒤처지는 모바일.
