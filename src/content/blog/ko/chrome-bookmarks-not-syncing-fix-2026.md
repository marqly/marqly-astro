크롬 북마크 동기화 문제의 대부분은 **동기화 일시중지**, 기기 간 **구글 계정 불일치**, 또는 설정에서 북마크 동기화가 꺼져 있기 때문에 발생합니다.

다음 8가지 해결책을 차례대로 적용해 보세요.

작업 전 필수 권장: **북마크 백업.** 북마크 관리자(`Ctrl/Cmd+Shift+O`) → 메뉴 ⋮ → **북마크 내보내기**를 통해 HTML 파일로 백업해 두세요.

## 1. 동기화 일시중지 여부 확인

1. 크롬 우측 상단 프로필에 경고 아이콘이 있는지 확인합니다.
2. **chrome://settings/syncSetup**으로 이동하여 "동기화 일시중지됨" 상태라면 다시 로그인합니다.
3. 모든 기기에서 동일하게 확인합니다.

## 2. 모든 기기에서 동일한 구글 계정 사용 확인

**chrome://settings**에서 각 기기의 이메일 주소를 확인하세요. 회사 계정의 경우 관리자 정책(**chrome://policy**)에 의해 동기화가 차단되어 있을 수 있습니다.

## 3. '동기화 항목 관리' 확인

**chrome://settings/syncSetup** → **동기화 항목 관리**에서 **북마크** 항목이 켜져 있는지 확인합니다.

## 4. 동기화 껐다 켜기 및 계정 재로그인

1. **chrome://settings/syncSetup**에서 동기화를 끕니다.
2. 크롬을 재시작한 뒤 동기화를 다시 켭니다.
3. 해결되지 않으면 크롬에서 구글 계정을 완전히 로그아웃 후 다시 로그인합니다.

## 5. 크롬 브라우저 최신 버전 업데이트

**chrome://settings/help**에서 크롬을 최신 버전으로 업데이트하여 동기화 프로토콜 충돌을 방지합니다.

## 6. chrome://sync-internals로 진단

주소창에 **chrome://sync-internals**를 입력하여 확인합니다:
- **Transport State:** **"Active"** 상태여야 합니다.
- **Username:** 로그인된 계정을 확인합니다.
- **Type Info → BOOKMARKS:** 북마크 항목의 동기화 상태를 확인합니다.

## 7. 구글 대시보드에서 동기화 초기화

1. HTML 백업 파일이 있는지 확인합니다.
2. **chrome.google.com/sync**에 접속하여 하단의 **동기화 재설정**을 클릭합니다.
3. 가장 완전한 북마크가 있는 기기에서 동기화를 다시 시작합니다.

## 8. Bookmarks.bak 파일로 사라진 북마크 복구

1. 크롬을 완전히 종료합니다.
2. 프로필 폴더(Windows: `%LOCALAPPDATA%\Google\Chrome\User Data\Default`, Mac: `~/Library/Application Support/Google/Chrome/Default`)를 엽니다.
3. `Bookmarks`를 `Bookmarks.old`로 바꾸고 `Bookmarks.bak`을 복사하여 `Bookmarks`로 이름을 변경합니다.
4. 크롬을 다시 실행합니다.
