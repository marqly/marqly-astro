## 1. Marqly — アカウントを持たない生徒へ教材リストを渡すのに最適

Marqlyが解決する教師固有の問題は、最後の一手です。ある単元のために11本の読み物と1つの実験活動と2本の動画を厳選したとしても、教室いっぱいの生徒が開けなければ意味がありません。しかもアカウント作成とパスワードリセットに授業の20分を溶かすことなく、です。Marqlyのボードを公開共有すると、それは単なるウェブページになります。リンクをLMSに貼り、スライドに載せ、QRコードを印刷すれば、生徒はクリックするだけです。インストールも登録も不要で、共有は閲覧専用なので、厳選した内容を誰も編集したり削除したりできません。ボードはすべてのプランで無料です。つまりこの機能は一切支払わずに使えます。

二つ目の教師固有の強みは動画です。反転授業はたいていYouTubeの解説動画に依存していますが、この表の他のツールはすべてリンクしか保存しません。そのため8月に必要な90秒を見つけるには、2月に見直すしかなくなります。MarqlyはすべてのYouTube視聴ページにAIカードを表示し、ストリーミング要約と主要セクション、再生位置と同期したワンクリックコピー可能な文字起こし、そしてProではその文字起こしをもとに質問へ答えるチャットタブを提供します。動画をブックマークすると文字起こしが付いたまま残るので、後からライブラリ全体を「実際に話された中身」で検索できます。

検索こそProの料金を正当化する部分です。セマンティック検索は、忘れてしまったタイトルの文言を一致させるのではなく、内容を説明するだけで保存を見つけ出します。例えば「葉の断面図が出てくる光合成の動画」で引けます。Proでは保存のたびに自動でタグ付けと要約が行われるので、教師のブックマーク運用を殺しがちな整理の負担が最初から発生しません。

## 2. Diigo — 認証済み教育者向けの無料プランが最も充実

「教師が無料で使えるものは何か」という問いへの正直な答えがDiigoです。認証済み教育者向けの無料Teacherプランを公開しており、クラス用コンソールも含まれます。たまたま無料になっている消費者向けプランではなく、実際にごく普通の教育製品です。そして中核の強みもまた、この一覧で最も教室に近い形をしています。実際のウェブページの上に直接置ける複数色ハイライトと付箋で、グループ機能を使えばクラス全体が共有ライブラリに同時に注釈を付けられます。アウトライナーはそのハイライトを構造化された調査ドキュメントに変換するので、課題の形式としても本当に有用です。データはCSV・HTML・RSSのエクスポートとウェブAPIで持ち出しできます。

引き換えに、DiigoにはAIが一切ありません。自動タグ付けも、要約も、セマンティック検索もなしです。そして目に見えて開発が止まっています。Chrome拡張の最終更新は2024年、AndroidアプリはGoogle Playから姿を消し、公式ブログのドメインは死んでいます。無料プランは広告付きで、生涯のブックマーク数とハイライト数に上限があり、しかもDiigo自身のページでその上限の表記が一致していません（ブックマーク500〜1,000件、ハイライト100〜200件）。キャッシュページ、PDF注釈、全文検索はすべて有料で、年額40ドルです。

**こんな先生に最適：** 生徒が共通のテキストに書き込む、注釈中心の授業。そして最新ツールであることより教員無料を重視する教育者。**見送るべきケース：** 意味ベースの検索、更新されているアプリ、広告のない無料枠が欲しい場合。

- **メリット：** クラス用コンソール付きの、認証済み教育者向け無料Teacherプラン／実ページ上のハイライトと付箋／協働グループライブラリ／安い有料プラン／持ち出し可能なエクスポートとウェブAPI。

Raindropがやらないのは、あなたの代わりに探すことです。整理の完成度は世界水準ですが、検索は依然として自分で入力したタグとキーワードに依存します。どの料金プランにもセマンティック検索はありません。Pro（年額28ドル）は全文検索、保存時のStella AIによるタグとコレクションの提案、ページの恒久コピー、4色で無制限のハイライト注釈、日次バックアップを追加します。有用ですしMarqly Proより安いものの、依然として意味ベースではなくキーワードベースの形をしています。

## 4. Notion Web Clipper — 学校がすでにNotionを使っている場合に最適

すでにNotionで動いている学校にとって、Clipperは最も抵抗の少ない選択肢です。無料で、太っ腹な無料プランを含むどのNotionアカウントでも動き、クリップはデータベースに入るので、保存したすべてのリンクがNotionのプロパティ・ビュー・フィルター・タグを引き継ぎます。リソース表示ビューを持つ単元計画データベースは、教師の成果物として本当に良いものです。そしてNotionページの共有は、二つ目のツールなしで生徒のアクセス問題を解決します。オフラインモードは2025年に全プランへ搭載されました。

教室にとって重要な注意点が二つあります。一つ目、Clipper自体は非常に簡素です。クリップ時にタグもノートもハイライトもスクリーンショットもなく、保存先を選ぶだけです。そしてNotion自身のドキュメントが、クリップの再現性は一定せず書式が失われることがあると警告しています。ワークシートを保存するとき、これは現実のリスクです。二つ目、誰もが欲しいAIは、ほとんどの学校が入っているプランには含まれていません。実用的なAI検索とチャットには1人あたり月額20ドルのBusinessプランが必要です。公式のブラウザ対応もChromeとSafariに狭められました。

**教育割引は大半の学校教員を対象外にしています。ここははっきり書いておく価値があります。** Notionの無料Education Planが対象とするのは、**認定された大学・短期大学**に在籍する学生と教員という「個人」です。Notion自身の資格ページには、あなたが「K-12（幼稚園から高校相当）の生徒またはK-12の教員」であれば対象*外*だと明記されています——その場合でも、通常の無料プランはそのまま使えます。加えて、World Higher Education Database（WHED）に掲載された教育機関の学校メールアドレスが必要で、学生証やその他の書類は受け付けないと明言されています。ワークスペースは最大100人のゲストを招けるものの**1メンバー**に制限され、一つの学校メールアドレスで申請できるのは一度きり、そして資格は毎年1回再認証しなければなりません。そのワークスペースをPlus、Business、Enterpriseへアップグレードすると、教育資格は恒久的に失われます。したがって小学校・中学校・高校の教員にとって、Notionは無料ではなく有料の判断になります。

**こんな先生に最適：** 無料のEducation Planの資格を持つ高等教育機関の職員と学生。そして教材をノート・プロジェクト・タスクの隣に置きたい、すでにNotionへ支払っているNotion前提の学校や教科。**見送るべきケース：** K-12で教えていて無料の教育プランを当てにしていた場合、書式付きワークシートで確実なクリップ再現性が必要な場合、またはAI検索が目的なのにBusinessプランに入っていない場合。

- **メリット：** Clipperは無料で無料プランでも動く／データベースのプロパティによりビューとフィルターが無料で手に入る／ノート・タスク・教材を一つのワークスペースに／公式APIとモバイルの共有シートからの保存／全プランでオフライン対応／資格を持つ大学の職員と学生には無料のEducation Plan。
- **デメリット：** **無料のEducation PlanはK-12の教員と生徒を対象外にしています**／1ワークスペースにつき1メンバーで、毎年再認証が必要／保存時にタグ・ノート・ハイライトがない／ドキュメント化されたクリップ再現性の問題／AIには1人あたり月額20ドルのBusinessプランが必要／ブラウザ対応がChromeとSafariに縮小／大きなデータベースへの保存は遅くなることがある。
- **料金：** Clipper無料／Notion Plus 1人あたり月額10ドル／Business 1人あたり月額20ドル（年払い）／無料のEducation Planは、認定された大学・短期大学に在籍する個人のみが対象です。

## 5. Pinterest — 視覚系の教科に強く、探し直しには最も弱い

美術、デザイン、小学校の教室掲示、そして教材そのものが画像であるあらゆる教科では、Pinterestの発見力にかなうものはこの一覧にありません。関連ピンとLensの視覚検索が1件の保存を類似アイデアの流れに変え、ボードはセクションと共同編集者で視覚的に整理でき、ピン数やボード数に上限はありません。完全に無料で、この分野で最も幅広いプラットフォーム対応を持ちます。

同時にこれはソーシャルな発見製品であって、プライベートなブックマーク管理ツールではありません。その違いは教師の実際の時間を奪います。プロモーションピンはおおむね4〜6ピンごとに現れ、有料でも消せないので、授業準備の時間がフィードの閲覧に流れます。リンク切れは常態で、ピンは指しているページより長く生き残り、スパムブログへ飛ぶことが日常的です。それはまさに、教材に依存する授業の朝には絶対に避けたい故障です。自分の保存の探し直しも弱く、検索はタイトルと説明に対するキーワードのみで、タグも全文検索もありません。テキストの取り込みもハイライトもありません。

**こんな先生に最適：** 視覚系の教科とアイデア発見。本格的なブックマーク管理ツールの補助として。**主軸として見送るべきケース：** 保存した特定のページを確実に見つけ直す必要がある場合。

- **メリット：** 並ぶものがない視覚的発見／上限なしで無料／優れた視覚的ボード整理／最も幅広いプラットフォーム対応。
- **デメリット：** おおむね4〜6ピンごとの広告で、消す手段がない／常態化したリンク切れ／自分の保存の検索が弱い／テキスト取り込みもハイライトもない／記事には不向き。
- **料金：** 無料で広告あり。消費者向けの有料プランはありません。

## 6. Evernote Web Clipper — すでにEvernoteを使っている先生に

EvernoteのClipperは、ここで最も能力の高い取り込みツールです。主要5ブラウザすべてで動き、クリップ時にタグ・備考・保存先ノートブックを追加でき、ページ全体、簡易記事、選択範囲、ブックマーク、注釈付きスクリーンショットの各モードを備えます。検索は最高水準で、画像の中の文字を読むOCRがあり、有料プランはPDFやドキュメントの中身も検索します。Evernote v11で本物のAIが加わり、ノート全体を横断して対話するアシスタント、セマンティック検索、AI会議メモが使えるようになりました。

教師にとっての問題は無料プランで、実質的にデモです。50ノート、1ノートブック、1デバイスです。使い続けるには支払いが必要で、Evernote Starterは月額14.99ドルまたは年額99ドル、Advancedは月額24.99ドルまたは年額249.99ドルと、このカテゴリでも最上位の高さです。オーナーのBending Spoonsの下で値上げが繰り返されてきました。自動タグ付けはないのでクリップは依然として手作業の整理を要し、実ウェブページ上のテキストをハイライトすることもできません。書き込みはクリップ後にノートの中で行います。

**こんな先生に最適：** すでにEvernoteに課金していて、ウェブコンテンツ・PDF・スクリーンショットをノートの隣で検索したい教師。**見送るべきケース：** 機能と予算でブックマーク管理ツールを選んでいる場合。リンクの保存と検索だけに重量級のノート基盤は過剰です。

- **メリット：** 5ブラウザ対応のClipper／クリップ時のタグと保存先／OCRとPDF検索／v11の本物のAI／有料プランでオフライン対応の成熟したアプリ。
- **デメリット：** 無料プランは50ノート・1ノートブック・1デバイス／高額／自動タグ付けなし／実ページ上のハイライト不可／ブックマーク目的だけでは過剰。
- **料金：** 無料（50ノート）／Starter 月額14.99ドルまたは年額99ドル／Advanced 月額24.99ドルまたは年額249.99ドル。

## 7. ブラウザのブックマーク — どの学校にも既にある無料の基準点

Chrome、Edge、Firefox、Safariのブックマークは無料で、即時に使え、自社のエコシステム内で同期し、研修も不要です。数十件のリンクなら正当な答えであり、それ以外を装うのは教師の夜を無駄にします。

問題は、まさに1学年が生み出す規模で崩れることです。整理はフォルダのみなので、教材は一か所に置くか重複させるかの二択になります。検索はタイトルのみなので、「無題」で保存したページは失われます。何も取り込まれないので、リンク切れが教材そのものを持ち去ります。そして内容を説明してページを見つける手段もなく、ファイルをエクスポートしてメールに添付せずにコレクションを生徒へ渡す方法もありません。この表の他のすべてのツールは、この4つの穴のために存在しています。すでにその先へ進んでいるなら、[ブラウザのブックマークを取り込み](/migrate)、毎週使う20件のリンクだけに基準を上げてください。

**こんな先生に最適：** 毎週使う、少なくて安定したリンク集。**見送るべきケース：** 翌年の単元のために保存し始めた瞬間、またはクラスに共有する瞬間。

- **メリット：** 無料／すでにインストール済み／学習コストなし／自社エコシステム内で同期。
- **デメリット：** フォルダのみの整理／タイトルのみの検索／取り込みがないためリンク切れで教材が消える／生徒に共有できない。
- **料金：** 無料。

## 教師はどれを選ぶべきか

機能一覧ではなく、実際に効いてくる制約にツールを合わせてください。

- **アカウントを持たない生徒に教材リストを共有する** → **Marqly。** 公開ボードは無料で、単なるウェブページとして開きます。
- **教員向けの無料が決定的な条件** → **Diigo。** 認証済み教育者向けの無料Teacherプランを公開している、ここでの唯一のツールです。
- **数百件保存するが支払う気はない** → **Raindrop.io。** 無料でもブックマークとコレクションが無制限です。
- **学校がすでにNotionで動いている** → **Notion Web Clipper。** ワークスペースは一つで、クリップはデータベースの行になります。
- **担当教科が視覚系** → 発見には**Pinterest**、探し直しには本物の管理ツールを併用。
- **すでにEvernoteに課金している** → **Evernote Web Clipper。** 最も豊富な取り込みモードとOCR検索。
- **リンクは20件程度** → **ブラウザのブックマーク**で、最適化はやめましょう。

ほとんどの教師にとって正直な結論は、一つのツールがすべての項目で勝つことはない、ということです。教材リストを生徒に届ける必要があり、今夜の整理より来年の8月に見つかることのほうが重要なら、Marqlyが最適です。予算がゼロでクラスが一緒に注釈を付けるならDiigo、問題が件数そのものならRaindrop.ioです。

## 1学年を通して本当に効く3つのポイント

教師のブックマーク運用が6月まで生き残れるかを決める故障は三つあり、いずれも機能の話ではありません。

**整理のコスト。** 保存時に判断を求める仕組みは、授業準備が立て込む期間に必ず放棄されます。だから賢いフォルダ体系より自動タグ付けのほうが重要で、MarqlyはそれをProに置き、Raindropはコレクションの手作業での構築を求め、Evernoteは毎回ノートブックを選ばせます。

**検索までの時間差。** 教材を保存してから必要になるまでの間隔は、往々にして10か月です。タイトル以外の記憶がないため、タイトルのみ検索はこの距離で機能しません。「分数を操作できる、あの教材」と説明して正しい保存を取り出せるセマンティック検索だけが、この表の中で時間差を埋められる能力です。そしてMarqlyでもEvernoteでもPro限定です。

**リンク切れ。** 授業の朝に404になる教材は、そもそも保存していなかった場合より悪い結果です。ページの恒久コピー（Raindrop Pro）、ローカルでのPDF保存（Marqly、ChromeとEdgeで処理）、キャッシュページ（Diigoの有料プラン）が、ここに実在する三つの防御策です。ブラウザのブックマークとPinterestはどれも備えておらず、Pinterestのリンク切れは計画に織り込むべきレベルで常態化しています。

この三つがあなたの問題なら、[Marqlyはまさにその三点を中心に作られています](https://app.marqly.com)——生徒がアカウントなしで開けるボード、動画と一緒に残る文字起こし、そしてタイトルではなく意味で引く検索です。まず無料プランで始めて、既存のブラウザのブックマークを取り込み、来年の単元が本当に見つけられるか確かめてください。[Marqly vs Notion Web Clipper](/ja/compare/marqly-vs-notion)や[Marqly vs Evernote Web Clipper](/ja/compare/marqly-vs-evernote)で一対一比較を読み、上記の各行の背後にある基準は[テスト方法](/how-we-test)でご確認ください。
