Voici la réalité décevante : **l'archive officielle de données de X (Twitter) n'inclut pas vos signets**. Vous pouvez télécharger vos posts, vos likes, vos messages privés et vos listes, mais les centaines de ressources et d'idées que vous avez marquées au fil des ans sont purement et simplement ignorées.

En 2026, si vous voulez préserver vos signets X avant qu'ils ne disparaissent sous la limite d'affichage, voici les démarches concrètes qui fonctionnent.

## Pourquoi exporter ses signets X est si contraignant

Trois contraintes imposées par la plateforme expliquent ce problème :

- **Absence des signets dans l'export officiel :** Aucun fichier `bookmarks` n'est présent dans le ZIP fourni par X.
- **Plafond d'affichage d'environ 800 à 1 000 éléments :** Les signets plus anciens cessent d'apparaître dans le flux déroulant.
- **Recherche et dossiers réservés à X Premium :** Les utilisateurs gratuits n'ont droit qu'à une liste chronologique brute, sans moteur de recherche interne.

## Solution pratique : l'extension de navigateur

La démarche la plus efficace consiste à employer une extension de navigateur sur Chrome :

1. Installez une extension d'exportation de signets X depuis le Chrome Web Store.
2. Ouvrez **x.com/i/bookmarks** dans votre session connectée.
3. Lancez l'outil : il fait défiler automatiquement votre collection pour enregistrer les liens.
4. Téléchargez le résultat sous forme de **fichier HTML de signets** ou CSV.
